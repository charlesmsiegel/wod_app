# Card images

Drop The Mage: the Ascension Tarot card images here (jpg, png, webp, gif
or avif) and reload the page. Files are matched to cards by name, e.g. `The Fool.jpg`,
`00-the-fool.png`, `Six of Pattern.jpg`, `pentacles-06.jpg`. Name the card
back `back.jpg` or `card-back.jpg`. See the main README for the full rules.

Artwork may be committed so that GitHub Pages can serve the complete deck.
Only add scans with permission for public hosting.
