# World of Darkness: Apps

![](https://www.code-inspector.com/project/27402/score/svg)
![](https://www.code-inspector.com/project/27402/status/svg)

For now, this repo will collect various apps I am constructing to help in my World of Darkness games. Eventually, they will be merged with an interface in order to integrate them into an ST Toolkit. The following apps are planned:

* Mage: the Ascension Tarot Reader
* Character Sheet Manager
* Chronicle Organizer

Ideally, I will do things in such a way that an ST can select which books are permitted in their game and it will filter things to show the appropriate mechanics, Merits/Flaws, etc., including changes to the Character Sheet (particularly with the WoD20 and V5 alterations). Storyteller's Vault products will be included in some cases. First priority will go to Mage and specifically M20, however.

It will also be built from the start with a single database in order to both firm up my SQL and to allow integration once basic independent infrastructure is complete.
